本页特别注意：`cn`（中国大陆）需要 AppId 获得中国区访问权限，且中国大陆客户端应使用 `ns.photonengine.cn`；普通海外 AppId/客户端测试建议先使用 `hk` 或 `asia`。

说明：Photon Cloud 会先通过 Name Server 获取区域信息，再连接指定 Region 的 Master Server，之后才进入 Game Server/Room。不同区域是彼此独立的；因此“Master 能连上但进房间失败”与“完全无法连接”是两类问题。
